# Dance OS Demo

这个目录服务 `Dance OS` 方向的 demo。

## 当前定位

它不是内容入口页，也不是旧站承接页。

它更适合承担：

- `动作反馈`
- `回看与纠错`
- `问题结构化`
- `下一轮回流`

也就是：

**把“录一轮 / 回看 / 只修一个点 / 写下下一步 / 判断会不会回来”做成最小可验证工具链。**

## 当前应该聚焦

- 动作反馈
- 练习结构化
- 回看与纠错
- 工具型界面

## 当前不该混进来的东西

- 低门槛内容入口页逻辑
- 直播排期 / 内容承接主壳
- 旧站 why latin / fit check 这类 frontdoor 入口语言

## 推荐入口

- 来自 `sites/frontdoor/dance-os`
- 后续独立孵化主位置：
  - `apps/demos/dance-os-demo/`

## 推荐输入

- 当前状态：
  - 断练后重启
  - 拍子总乱
  - 已经知道卡点
  - 准备录切片
- 当前舞种：
  - 伦巴
  - 恰恰
  - 桑巴
- 当前落点：
  - 重心
  - 髋
  - 脚下
  - 上身

## 推荐输出

- 当前问题先落在哪个身体部位
- 这一轮只修哪个点
- 下次回来先执行哪一句动作句
- 这轮 witness 是否值得归档
- 用户会不会真的回来下一轮

## 当前验证方式

- 用户能不能说清“这轮只改哪里”
- 用户能不能留下下一轮动作句
- witness archive 能不能稳定沉淀
- queue / archive / return trigger 能不能证明真实回流

## 当前边界结论

Dance OS Demo 更像：

- `第一批最适合独立孵化的 Top 1 demo`
- `产品化验证主壳`

因为它比 Daily Latin 更工具化，也更适合先在 `apps/demos/` 中长成独立资产。
