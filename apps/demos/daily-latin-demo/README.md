# Daily Latin Demo

这个目录服务 `Daily Latin` 方向的 demo。

## 当前定位

它不是完整内容站，也不是旧站替代品。

它更适合承担：

- `状态分流`
- `10-15 分钟起步闭环`
- `从围观到做一轮`
- `witness / return`

也就是：

**把“今天怎么开始、这一轮怎么做完、做完后怎么回来”做成最小可验证入口。**

## 当前应该聚焦

- 今天怎么开始练
- 低门槛起步页
- 直播 / 日更 / 日练 的入口承接
- 从“围观”到“做一轮”的过渡

## 当前不该混进来的东西

- Dance OS 的纠错工具壳
- Body Map / Correction Ledger 这类工具型模块
- 过重的后台 / dashboard / admin 逻辑

## 推荐入口

- 来自 `sites/frontdoor/daily-latin`
- 后续如需独立 demo，可继续保留：
  - frontdoor route 作为承接页
  - `apps/demos/daily-latin-demo/` 作为独立实验壳

## 推荐输入

- 用户当前状态：
  - 完全没开始过
  - 断练后重启
  - 已有具体卡点
  - 刚看完直播 / 切片
- 舞种：
  - 伦巴
  - 恰恰
  - 桑巴

## 推荐输出

- 这一轮该怎么开始
- 这一轮只做什么
- 下次回来先改哪里
- 是否桥接到 Dance OS

## 当前验证方式

- 用户能不能在 10-15 分钟内做完一轮
- 做完后能不能留下 1 句 witness
- 下一轮能不能从 witness 重新回来

## 当前边界结论

Daily Latin Demo 更像：

- `frontdoor 入口分支`
- `内容回流入口`

而不是第一批最适合独立孵化的重工具应用。
