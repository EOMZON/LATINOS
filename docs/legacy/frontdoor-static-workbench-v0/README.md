# Frontdoor Static Workbench V0

这是 `LATINOS frontdoor` 迁到 `Next.js App Router` 之前的静态工作台版本归档。

## 归档原因

- 这套静态稿是新前台视觉方向的重要过渡版本，不应该丢失。
- 但当前主前台已经迁到：
  - `sites/frontdoor/app/`
  - `sites/frontdoor/components/`
  - `sites/frontdoor/data/`
- 如果继续把旧静态稿直接留在 `sites/frontdoor/` 根下，会让后续 agent 混淆：
  - 哪套才是当前主实现
  - 哪些文件只是历史版本
