关于这条线

这不是只做一个网站，而是在搭 Latin Dance OS

project identity

这条线真正要解决的，不是“怎么做一个拉丁页面”，而是怎么把拉丁这件事组织成一个长期会越长越清晰的系统。飞书里已经很明确：这里至少有三条并行线——Daily Latin IP、拉丁成长网站、Dance Tools / Dance OS。

四层目标

保留 proof —— 旧站已经是公开证据，不需要因为结构重做而抹掉。

重建入口 —— 新 frontdoor 负责把旧站、新 demo、来源文档和路线图收进同一个前台节奏里。

做成 demo —— 不只是内容站，还要长出 Daily Latin 和 Dance OS 两条产品化分支。

未来再切 production —— 域名切换不是第一步，是后面的结果。

为什么强调 Feishu first

因为真实工作内容已经在飞书里，继续让 Notion 和 Feishu 双轨并行，只会让结构再次变乱。这个仓库从今天开始只认飞书为主来源。

今天最重要的事情

不是争论“旧站要不要废掉”，也不是急着绑新域名，而是先把：旧站保留、新入口可看、两个 demo 有位置、规则写清楚 这四件事同时成立。
