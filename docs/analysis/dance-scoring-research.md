# 拉丁动作打分:数据集调研与方案设计

> 2026-07-27 | 关联:`拉丁舞动作维度梳理档案.md`、`拉丁舞骨骼可视化直播构想_原话记录.md`
> 产出:`apps/demos/skeleton-live/` v0.2(身体版骨架 + 跟练打分 v0)

## 一、结论先行

**没有现成的拉丁/国标骨骼开源数据集。** 公开舞蹈数据集里没有 ballroom/Latin 品类,
所以「标准数据」的正确路径不是找数据集,而是**自建参考库**:把老师示范视频(或自己满意的一遍)
用 demo 提取成骨骼 JSON,这个 JSON 就是「标准答案」。v0.2 已支持这个闭环。

## 二、公开数据集调研(2026-07-27 检索)

| 数据集 | 规模 | 舞种 | 与本项目的匹配度 |
|---|---|---|---|
| **AIST++**(Google,ICCV 2021) | 1408 段、5.2h,多视角重建 3D 关键点 + 音乐 | 10 种**街舞**(breaking、pop、lock、waacking、hiphop、house、krump 等) | ❌ 无拉丁/国标;且是生成任务数据,不是「标准动作范本」 |
| **FineDance**(ICCV 2023) | 14.6h、27 名职业舞者、Vicon 动捕、52 关节、22 个细分类 | 以街舞、中国古典舞、民族舞为主 | ❌ 无拉丁;精度高(Vicon 动捕)但舞种不对口 |
| NTU RGB+D 120 等动作识别库 | 11 万+ 样本 | 日常动作 | ❌ 与舞蹈无关 |

判断:学术界的舞蹈数据集中,「音乐→舞蹈生成」是主流任务,**拉丁/国标因为双人持位、
版权问题,几乎没有公开骨骼数据**。等数据集不现实,自建参考库反而更贴合个人训练:
标准就是「你的老师」或「你最好的那一遍」。

## 三、打分方案调研:业界怎么做「舞动全开式」打分

检索到的开源实现与论文,技术路线高度一致:

| 参考 | 路线 |
|---|---|
| DanceCompare(GitHub, 2026) | MediaPipe 33 关键点 → DTW 对齐 → 关节角余弦相似度 → 0–100 分 + 分段时间轴热力图 |
| OpenPose_DanceComparing(GitHub, 2024) | OpenPose 关键点 → 关节角差值 → fastdtw → 差异关节高亮视频 |
| 康复评估论文(MDPI Sensors 2019 等) | 骨向量夹角求和作为帧间距离 → DTW → 归一化为 0–100 客观分 |
| 体育训练姿态评估(多项研究) | 8 个核心关节角(双肩/双肘/双髋/双膝) + DTW,偏差超阈值的关节点名反馈 |

**共识公式**:关节角度特征(不是原始坐标)+ 时间对齐(DTW 或同步)+ 逐部位偏差反馈。

我们 v0.2 的实现与这个共识对齐:
- 特征:9 维角度(左/右肩、肘、髋、膝 8 个关节角 + 躯干倾斜角),不用原始坐标
  → 天然免疫身高、站远近、镜头位置差异
- 归一化:双髋中点为原点、肩宽为单位长度
- v0 用「同步跟练」对齐(参考序列按时间走,跟着跳);**v1 计划 DTW**,解决跳快跳慢掉分的问题
- 部位反馈:臂=肩+肘、腿=髋+膝、躯干=倾斜角,偏差大的部位骨架连线染黄/红

## 四、对照《拉丁舞动作维度梳理档案》:哪些维度机器能判

| 档案里的维度 | 2D 骨骼可判性 | 说明 |
|---|---|---|
| 膝盖松懈/锁死、腿伸直 | ✅ 直接可判 | 膝关节角度特征已覆盖 |
| 肩胯对抗(出左脚右肩前) | ✅ 大致可判 | 肩线-髋线夹角可加为特征(v1) |
| 旋转轴心垂直、中轴 | ✅ 可判 | 躯干倾斜角已覆盖 |
| 重心踩实主力腿、重心转换 | 🟡 部分可判 | 髋中心左右位移轨迹可近似,v1 可加 |
| 塌腰/骨盆前置、肋骨外翻 | ❌ 2D 难判 | 需要侧面机位或 3D(world landmarks 或双摄) |
| 肌肉收紧、脚踝持续发力 | ❌ 不可判 | 骨骼数据看不出肌肉状态;脚踝角度在 2D 正面机位噪声大 |
| 节奏卡点 | 🟡 v1 可做 | 动作速度/加速度峰值对齐音乐节拍(librosa 思路) |

**建议机位**:正面、全身入画、2–3 米距离。侧面机位能补上塌腰/骨盆维度,可作为后续实验。

## 五、路线图

- **v0.2(已完成)**:身体版骨架、参考录制/导入导出 JSON、同步跟练打分、部位染色
- **v1**:DTW 回放对齐(跳完一遍整段评分,不怕快慢);肩胯对抗角、重心轨迹加入特征;按舞种/动作建立参考库目录(`data/references/<舞种>/<动作>.json`)
- **v2**:world landmarks(伪 3D)补前后向动作;音乐节拍对齐;训练报告页(历史分数曲线)
- **远期**:积累够多「标准 vs 常见错误」样本后,可以训练一个小分类器直接输出「膝盖松懈」「Ronde 轨迹缩水」这类语义化反馈——那才是档案里易错清单的完整自动化
