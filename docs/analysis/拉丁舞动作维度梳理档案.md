## 二、各舞种 · 动作维度与要点

### 🟤 伦巴 Rumba ——「慢、柔、拧」

**核心口诀（0629 专项）**：膝盖后让 → 臀收紧 → 骨盆前置｜收腹关肋 → 胸腔上提 → 背拉直｜体态固定 → 整块转动 → 无断层移动

| 动作维度 | 关键要点 |
|---|---|
| **基础体态 / 骨盆发力**（0629、0413） | 后退膝盖向后松弛让位（不锁死）；臀收紧向前顶推、尾骨微收、骨盆前置；杜绝塌腰后撅。肚子是「平、收、提」，不鼓不塌 |
| **中段核心**（0629） | 骨盆收紧后腹部自然上提内收；两侧肋骨向内向下关紧，拒绝外翻；胸腔向上向前延展，不用肚子顶 |
| **脚步 / 膝盖顺序**（0413） | 膝前 → 脚前顶 → 胯后开 + 胸前送；左腿全程伸直固定，右腿负责向后分配力量；转动靠脚后跟内侧 / 脚外沿发力，非身体甩动 |
| **前后行进步**（0519、0429） | 主力腿绷直支撑，动力腿轻缓延伸；脚步走斜 45° 方位不直线；顺序：先落脚 → 再移重心 → 最后带胯转动 |
| **胯部律动 / 绕胯**（0519） | 左右交替绕胯，腰腹带动（非甩胯）；前行胯前推、后退胯内收；上半身稳住不动、仅胯与下肢转动 |
| **定点转 & 原地旋转**（0519） | 单腿主力承重，另一腿仅脚尖点地；先 180° 半圈找轴心，再连贯整圈；中轴垂直地面，头部平稳留视 |
| **身体对抗**（0413、0429） | 左肩前、右肩后形成斜向拧转对抗；肩膀不随胯同向转；胸腔持续前送、背有支撑 |
| **原地古巴律动（立体八字胯）**（0703 直播素材） | 单侧肋骨收紧 → 同侧骨盆向上挤压抬起 → 向内旋转换边 → 左右闭环成立体 8 字（非平面平扭胯）；下肢扎根、仅中段隔离律动 |

**伦巴高频易错**：主力腿膝盖松懈、转体时上半身跟着晃、用腰蛮力甩胯、步幅跑偏、肚子外凸肋骨外翻。
**感悟原话**：「伦巴的柔美质感全藏在细节里——内收的核心、紧致的腿型、圆润的绕胯、沉稳的重心，缺一不可。」

### 🔴 恰恰 Cha Cha ——「快、脆、弹」

**基础节奏**：Two Three Cha Cha One ｜ 摆荡律动 / Ronde 变式部分卡点 One & Three

| 动作维度 | 关键要点 |
|---|---|
| **摆荡版原地律动**（0703） | 压住肩膀向下对抗，克制身体向上窜；立跟阶段允许双膝弯、脚跟离地，收尾定格瞬间主力腿必须落跟踩实 |
| **重心转换与轴心旋转**（0702 美人鱼） | 重心落在哪条腿，哪条腿即旋转轴心；分段 90° 转向、正侧面交替；重心全程向前推，忌后退压缩空间 |
| **骨盆 / 躯干律动**（0702） | 主动向前推送骨盆带动胯律动；胸腔前舒、背拉直，杜绝塌腰后仰；由低缓慢升起的起伏节奏 |
| **手臂 / 手部动线**（0702） | 右手：上抬 → 后环绕 → 下落；左手：侧出 → 前勾伸；双手掌心同步下压定格；手位略靠前于胯部 |
| **节奏层次**（0702，核心难点） | 松弛蓄力 → 瞬间收紧定格循环；重拍节点加重肢体表达，过渡节拍放缓；动作留白、卡点再回收 |
| **前进后退 Check 锁步**（0703） | 后退 Check 易形成生硬拉丁交叉 → 落脚微向外侧偏一小段规避；场地受限时可小幅拎后脚缩短距离 |
| **Ronde 朗德追步变式**（0703 重难点） | 动力腿向外画大圆扫出（≠ 向内回收的搅拌步）；膝盖仅微弯、发力趋势向上拎，胯部持续上提；卡点 One & Three |
| **搅拌步**（0703） | 脚步以内圈环绕搅拌完成，属左右平移体系 |
| **成品组合走位**（0702） | 横向重心切换配滑动步；持续更换主力重心脚；收尾身体侧扭转、胸腔前探、手臂走完环绕轨迹 |
| **双人演绎**（0702） | 本支情绪底色「不舍 / 遗憾」，带入眼神交流与肢体留白，不只复刻脚步框架 |

**通用万能发力逻辑（0703）「上代下」**：原地律动 / 时间步 / 快速时间步 / 搅拌步共通——由中段核心先发 → 带动胯 → 再带动双脚，拒绝「脚先走、身体滞留」。提速时上身依旧稳定优雅。
**恰恰高频易错**：摆荡律动肩膀失控晃动、Ronde 轨迹缩水成搅拌步、膝盖屈幅过大重心下坠、手脚节奏割裂、女士风格生硬缺流转感。

### 🟡 牛仔 Jive ——「弹、俏、对抗」

**风格核心**：向下 Bounce 弹动（严禁向上腾空跳跃）+ 肩胯反向 X 型对抗。

| 动作维度 | 关键要点 |
|---|---|
| **基础站姿**（0508） | 双脚与肩同宽；膝盖微弯、骨盆收紧不外送；脚踝内侧主动发力承压、脚尖抓地；上身直立不随胯偏移 |
| **原地摆荡**（0508） | 标准三步：落跟 → 踩直主力腿 → 弯曲另一膝；双腿像电梯升降配合，重心全程在蹬直主力腿 |
| **重心置换摆荡**（0508） | 双腿升降交替 + 胯部左右摆动 |
| **弹踢 Kicks**（0508） | 单腿两次连续弹踢为一组，双腿交替；幅度宁小勿大，核心持续收紧 |
| **膝盖 / 脚踝控制**（0508） | 膝盖正对前方不内扣；脚踝全程立起、靠脚跟向前施压；双腿内侧夹紧成三角支撑 |
| **醉酒步 Drunken Step**（0612 / 0703） | 动力腿向对侧斜后方穿插交叉；脚步移一侧、对侧躯干向前包裹拧转，形成 X 型肩胯反向张力锁轴心 |
| **Cross Back 后斜交叉步**（0612 / 0703） | 固定斜后内侧走线，禁向前 / 纯向旁摆腿；手脚反向发力，单侧肩前送 |
| **Bob 原地下沉弹动**（0612 / 0703） | 单肩宽度内活动；全程向下压缩蓄力，**严禁向上蹦跳**，是牛仔松弛弹性来源 |
| **Leg Flick 前弹踢**（0612 / 0703） | 主力腿下沉屈膝蓄力，动力腿完全绷直脚尖弹出，踢完沿直线贴靠主力腿收回；不勾脚不松踝 |
| **Jive Basic / 进阶花式**（0612） | 衔接牛仔基础 Jive Basic 时，交叉跳保留落跟-踩直-屈膝过渡，不全程悬空 |

**牛仔高频易错**：弹动反向（向上跳）、双肩同步前后晃破坏 X 对抗、手脚不同步、交叉脚位做成前交叉、弹踢腿型松散不绷脚尖。
**感悟原话**：「牛仔看着随性松弛，核心全在于向下的控制力与身体对抗。沉下心打磨细节，慢慢积累，就能跳出轻盈又有质感的弹动状态。」

### 🟢 桑巴 Samba ——「弹、涌、垂直」

| 动作维度 | 关键要点 |
|---|---|
| **身体姿态**（0724 心得） | 上身必须垂直稳定，不能跳出街舞 Hip-hop 的松弛感；各舞种发力逻辑不同，肌肉记忆会冲突 |
| **身体扭转**（0724 1/8 课） | 身体分左右两侧，一侧前、另一侧后拧；转动胸、腰、胯、膝，胯部主动带动 |
| **核心稳定**（0724 1/8 课） | 核心像柱子一样稳定；尾椎往上收集再往后放，控制腹部 |
| **脚踝 / 腿部发力**（0724 心得） | 对脚踝力量、绷脚尖、腿部推力要求极高；全程脚踝持续立起发力 |
| **基础步初体验**（0724） | 首次系统上课生疏；有伦巴基础能看到细微进步，但每周仅 1–2 次课难快速形成稳定肌肉记忆 |

**桑巴要点提示**：与伦巴 / 牛仔差异明显——更强调向上的弹涌与脚踝持续支撑，而非下沉或平移律动。

### ⚪ 通用拉丁小班课动作维度（0703 优度舞蹈录音总结）

适用于伦巴 / 恰恰 / 牛仔共通的基础训练，涵盖最完整的「动作拆解 — 形体 — 手位 — 节奏」框架：

- **画圈延伸步**：先拉长直线延伸再回收，腿伸直、脚尖延展画标准大圆；主力腿踩实，胯不随意乱扭。
- **吸腿 / 踢腿**：靠大腿发力（非小腿）；吸后脚尖轻点支撑腿、踢完必须踩实另一侧主力腿才能换边；禁大幅向上蹦。
- **前后进退 / 旁开步**：旁步膝盖伸直；进退步膝盖有弹性不锁死；后退大腿内收紧、仅脚后落。
- **前旁后组合 + 沙斯（Salsa/恰恰短句）**：基础循环「沙斯 + 踢腿」交替；脚尖绷直禁勾脚，落地精准定点。
- **绕肩单侧反身**：出左脚 → 右肩 / 胸腔前；出右脚 → 左肩前；杜绝同手同脚；靠墙练改善含胸。
- **手臂手位**：一手肘弯向后、一手伸直向前，靠肩膀带臂不甩腕；中指下压做标准手型；带动裙摆飘动。
- **节奏拆分**：567 预备起势，常用 1234 / 5678 / and 切分；慢速拆单组 → 提速 → 串联成套。

## 三、跨舞种通用要点提炼（可直接当检查清单）

| 维度 | 通用原则 |
|---|---|
| **体态框架** | 收腹关肋、胸腔上提、背拉直、脊柱垂直；尾巴「平收提不鼓塌」 |
| **发力顺序** | 「上代下」——中段核心先发 → 胯 → 脚；肩背躯干引导再带手脚，不靠四肢单独发力 |
| **重心规则** | 所有转换必须踩实主力腿、完成重心切换，再衔接下一式 |
| **肩胯对抗** | 出左脚下右肩前、出右脚下左肩前，形成分层张力；禁双肩同步前后翻 |
| **旋转轴心** | 单腿承重、中轴垂直、分段 180°→ 整圈、头部平稳留视 |
| **节奏把控** | 快慢强弱对比：松弛蓄力 → 重拍收紧定格；动作留白卡点回收 |
| **易错共性** | 塌腰 / 肋骨外翻 / 同手同脚 / 向上蹦跳 / 脚先走身体滞留 / 手腕小臂乱甩 |
