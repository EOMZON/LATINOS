## 二、原话摘录（直接引用）

> 「就我觉得其实拉丁的话，那个身体倒是做得挺好的，而且那肌肉也挺好的。我前两天看到一个，一个博客，就是里面讲一个产品，好像就已经把那个健身的那个肌肉，就是那个肢体那个骨骼**可视化那个出来**。
>
> **我一直都想做呢，我一直都在想说我的直播什么时候做成这个样子，然后再去进行直播。**
>
> 但是每次让 AI 分析，它都不建议我去做。这条路径可能是这条路径做起来**消耗过多的成本**啊。一直不太支持我上来就做这么复杂的东西。
>
> 而且我其实**曾经尝试过，在本地调试效果一般**，而且我的电脑的性能确实也不一定能带动。
>
> 再加上直播这个方向，确实它也是你选的吧。大家还是更建议我去，先去吧，**合作自动化这条路线跑好**，而且这个确实也是直接导向我未来有可能赚到盈利的方向。所以说我现在还是没有把拉丁舞这个方向放在第一位。虽然我认为我要长期地去做这个事情，但是我现在还是个学习的人。我只能说平时还得把基本功捡起来去做练习。然后维持我身体这个状态和这个舞蹈基本的一个训练。」

## 三、想法拆解

| 维度 | 内容 |
|------|------|
| **是什么** | 直播跳拉丁舞时，实时对画面做人体骨骼/肢体关键点识别，把肌肉与骨架线条叠加可视化，让观众直观看到发力与体态（参考看到的一款「健身肌肉/肢体骨骼可视化」产品）。 |
| **为什么想做** | ① 认为拉丁舞「身体和肌肉做得挺好」，可视化能放大自身优势、做出差异化直播效果；② 看到现成产品已跑通类似效果，觉得「我的直播做成这样再播」是理想形态；③ 直播录制的素材本身引流效果比直播涨粉更好，想进一步提升内容质感。 |
| **尝试过的动作** | 曾在本地调试过骨骼可视化效果，但「效果一般」，且自认电脑性能带不动实时推理。 |
| **为什么搁置** | ① 成本过高：AI 多次分析都不建议优先投入这条高成本路径；② 硬件限制：本地算力不足、设备发烫，实时骨骼识别跑不动；③ 战略取舍：直播涨粉本身效果差，大家都更建议先把「自动化」主线（求职 Agent 等）跑通、导向盈利，拉丁舞降级为长期爱好而非第一优先级。 |
| **当前状态** | 已明确「放弃复杂可视化直播方案」；拉丁舞维持日常基本功训练，直播不作为核心赛道，仅用成熟打光方案录制素材做短视频引流。 |
