## 拉丁骨骼实时反馈 demo v0.1

- 触发:用户拿来 `拉丁舞骨骼可视化直播构想_原话记录.md`(2026-07-24 飞书语音复盘,原方案曾因成本/算力/战略取舍搁置),要求拆两部分实现:本地跑通 + 直播可见。
- 原始记录已归档到 `docs/analysis/拉丁舞骨骼可视化直播构想_原话记录.md`。
- 决策:用**浏览器内 MediaPipe Pose Landmarker**(WASM + WebGL)替代本地 Python 推理——零安装、吃 GPU、对机器负担小,直接回应了原话里"本地调试效果一般、电脑带不动"的顾虑。
- 产出:`apps/demos/skeleton-live/`(Vite + React + TS)。
  - 模型与 wasm 全部本地化(`public/models/` lite 5.8MB / full 9.4MB,`public/wasm/`),CDN 回退兜底。
  - 默认 640×480 + lite 模型省性能;镜像画面 + 骨骼叠加;FPS/delegate 状态角标。
  - 「直播模式」:纯绿 `#00ff00` 底只画骨骼,供 OBS 浏览器源 + 色度键抠像,这是直播可见部分的核心路径。
  - build 通过,dev server 验证后已关闭,无残留进程。
- 待验证:用户实机打开页面授权摄像头,确认 FPS 与骨骼效果(子代理环境无法测摄像头)。
- 直播链路结论(待用户实测后确认):本地推理在浏览器完成 → OBS 浏览器源叠加 → 推流,无需云端推理,零额外成本。
